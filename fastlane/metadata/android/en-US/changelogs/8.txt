Reproducible builds: this release is built exactly the way F-Droid builds it, so anyone can rebuild the APK from source and get a bit-for-bit identical result. Two build-system bugs were fixed to make that true — the bundled Rust core was being compiled with whatever Rust "stable" happened to be that day instead of the pinned 1.96.0, and the path-stripping flags that make builds machine-independent were being silently ignored. Both are corrected, and the release is now produced in the same container image F-Droid uses. No functional or user-visible changes from 0.1.6.
