Build integrity only — no functional or user-visible changes from 0.1.7. The Flutter SDK version is now pinned inside this repository and read from there by the F-Droid build, so the two can no longer drift apart. The build also now happens at a fixed path, because Flutter's compiled Dart snapshot and two plugin libraries bake the build directory into themselves; without that, a rebuild on a different machine produced different bytes and could not be verified against the released APK.
